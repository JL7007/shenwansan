# 使用教程网站科技风改版设计

## 目标

将网站首屏标题由“常见问题汇总”改为“使用教程”，删除首屏介绍文字，并在不改变现有教程内容、视频、图片及操作方式的前提下，把整站视觉升级为专业的深色 AI 科技风。

## 内容变更

- 浏览器标题由“常见问题汇总｜沈万三”改为“使用教程｜沈万三”。
- 首屏主标题由“常见问题汇总”改为“使用教程”。
- 删除首屏文案：“把账号使用、验证码、售后与故障处理集中到一个页面。遇到问题时，先按分类找到对应答案。”
- 保留顶部品牌、原始页面链接、两个快速入口、全部 FAQ、图片、视频、提示和页脚说明。

## 视觉方向

- 主背景使用深蓝黑色，主强调色使用青蓝，辅助强调色使用电紫色。
- 首屏增加纯 CSS 数字网格、径向光晕和细线装饰，不引入额外图片或远程资源。
- 顶部品牌标志、按钮、章节编号和展开控件使用冷色发光边框。
- FAQ、视频、先决条件和帮助区采用半透明深色玻璃卡片，使用清晰边框和轻微阴影建立层次。
- 标题使用现代无衬线字体栈；小标签和代码路径使用等宽字体，增强技术界面感。
- 图片保持原始颜色并放在深色框架中；原生视频播放器继续使用浏览器默认控制栏。

## 可读性与交互

- 正文保持足够的明暗对比，辅助文字不低于易读的灰蓝色。
- 链接、按钮、FAQ 展开状态和键盘焦点均使用可辨认的青蓝色反馈。
- 保留 `prefers-reduced-motion` 支持；装饰效果不影响内容读取和点击。
- 保留 760px 手机断点，按钮、导航、章节和图片在窄屏继续使用单栏布局。

## 文件改动

- `index.html`：修改页面标题与主标题，删除首屏介绍段落。
- `styles.css`：替换颜色变量、首屏背景、卡片、按钮、媒体、页脚及响应式视觉样式。
- `tests/test_site.py`：验证“使用教程”标题存在，旧首屏介绍文字不存在，同时保持现有内容和媒体测试。

## 验证与发布

- 自动测试必须继续验证 6 张本地图片、4 个本地视频、FAQ 结构及 Pages 工作流。
- 新增文案测试，确保标题已更新且被删除的介绍文字不再存在。
- 检查 CSS 与 JavaScript 语法、无未引用的旧配色变量，并通过本地 HTTP 访问确认资源返回成功。
- 推送 `main` 后等待 GitHub Pages 工作流成功，再从公网验证标题、样式表和全部本地媒体资源。
