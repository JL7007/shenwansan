# 沈万三常见问题网站设计

## 目标

将 Blogger 页面《常见问题汇总》的全部文字、6 张说明图片和 4 个教程视频整理为一个独立、易读、适合手机浏览的单页网站，并通过 GitHub Pages 发布到 `https://jl7007.github.io/shenwansan/`。

原始内容来源：`https://shenwansa.blogspot.com/2026/09/blog-post.html`

## 内容范围

网站保留原页面的两组内容：

1. 质保 30 天成品 PLUS 问题汇总
2. 直充／代充 PLUS 常见问题汇总

保留全部问题、答案、步骤、外部链接、6 张说明图片和 4 个视频。允许修正空格、标点和标题层级，但不改变原意，不增加未经确认的承诺。

## 方案选择

采用无框架的静态单页网站，由 `index.html`、`styles.css` 和 `script.js` 组成。它比原样复制 Blogger 更清晰，也比引入 React 等框架更轻量，适合内容型页面和 GitHub Pages。

## 页面结构

- 顶部首屏：网站标题、简短说明和两个主要内容入口。
- 快速导航：跳转到“质保 30 天成品 PLUS”和“直充／代充 PLUS”。
- 内容区：每个问题显示为可展开的 FAQ 卡片；关键提示使用强调卡片。
- 媒体区：图片与对应教程放在相关问题下方；视频使用响应式播放器卡片。
- 页脚：保留原始页面链接，方便核对来源。

## 视觉与交互

- 使用深绿色、金色和暖白色，形成清晰、可信的教程页面风格。
- 正文保持较高对比度，最大阅读宽度约 1100 像素。
- FAQ 支持鼠标、键盘和触摸操作，并使用原生语义结构保证可访问性。
- 手机端采用单栏布局；图片和视频按容器宽度自适应。
- 页面不依赖第三方 JavaScript、字体或运行时框架。

## 媒体处理

- 6 张图片下载到仓库的 `assets/images/`，页面不依赖 Blogger 图片地址。
- 4 个视频保留 Blogger 播放器嵌入，以避免把大型视频文件直接放入 Git 仓库。
- 每个视频提供明确标题和备用链接；播放器加载失败时，用户仍可打开原始内容页观看。
- 所有媒体都启用延迟加载，减少首屏等待时间。

## 文件边界

- `index.html`：页面语义结构和全部已确认文案。
- `styles.css`：配色、排版、响应式布局和交互状态。
- `script.js`：导航增强与小型交互；网站核心内容在禁用 JavaScript 时仍可阅读。
- `assets/images/`：6 张本地 PNG 说明图片。
- `.github/workflows/pages.yml`：GitHub Pages 自动发布流程。
- `README.md`：网站用途、本地预览和发布地址。

## 发布流程

代码推送到 `JL7007/shenwansan` 的 `main` 分支。GitHub Actions 构建静态站点并发布到 GitHub Pages。若仓库尚未启用 Pages，则在 GitHub 仓库设置中选择 GitHub Actions 作为发布来源。

## 异常与降级

- 图片下载失败时停止发布，避免交付缺图页面。
- 视频播放器因 Blogger 限制无法跨站显示时，保留醒目的备用观看链接，不影响其他内容使用。
- GitHub Pages 发布失败时保留已推送源码，根据 Actions 日志修复后重新发布。

## 验收标准

- 页面包含原博客全部文字、6 张图片和 4 个视频入口。
- 两组 FAQ 的标题、答案和顺序与原页面一致。
- 在常见桌面和手机宽度下无水平滚动，图片和视频不溢出。
- 所有内部导航、外部链接、FAQ 展开和备用视频链接可用。
- 静态文件可在本地打开，且 GitHub Pages 返回成功页面。
- 发布后的公开地址为 `https://jl7007.github.io/shenwansan/` 或 GitHub 返回的等效 Pages 地址。
