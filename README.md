# 沈万三常见问题网站

一个整理“质保 30 天成品 PLUS”与“直充／代充 PLUS”常见问题、图片和视频教程的响应式单页网站。

公开地址：[https://jl7007.github.io/shenwansan/](https://jl7007.github.io/shenwansan/)

## 本地预览

在仓库根目录运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 内容与媒体

文字、图片和视频顺序整理自[原始 Blogger 页面](https://shenwansa.blogspot.com/2026/09/blog-post.html)。图片保存在本仓库，视频使用 Blogger 播放器，并提供原页面备用入口。

推送到 `main` 分支后，GitHub Actions 会自动发布 GitHub Pages。
